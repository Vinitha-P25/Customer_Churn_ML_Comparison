# Customer Churn ML Model Comparison

This project compares different machine learning classification algorithms for predicting customer churn.

## Models Used

* Logistic Regression
* Decision Tree
* Random Forest
* Gradient Boosting
* K-Nearest Neighbors (KNN)
* Naive Bayes

## Techniques Used

* Train-Test Split
* Feature Scaling
* One-Hot Encoding
* ColumnTransformer
* Machine Learning Pipelines
* Cross-Validation
* Hyperparameter Tuning using GridSearchCV
* Feature Importance

## Model Evaluation

The models are evaluated using:

* Accuracy
* Precision
* Recall
* F1 Score
* ROC-AUC
* Confusion Matrix
* Classification Report

## Dataset

A synthetic customer churn dataset containing 1,000 customer records is created using Python and NumPy.

## Technologies

* Python
* NumPy
* Pandas
* Scikit-learn

## Project File

`customer_churn_ml.py` contains the complete machine learning workflow.
